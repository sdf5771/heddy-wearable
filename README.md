# Heddy Wearable 프로젝트

## 개요

**Heddy Wearable**은 강아지의 산책 및 활동 데이터를 실시간으로 측정하고, 블루투스 통신을 통해 데이터를 전송하는 웨어러블 디바이스입니다.  
심박수, 걸음 수, 이동 거리, 속도, 칼로리 소모량 등 다양한 건강 지표를 측정할 수 있습니다.

## 주요 기능

- **심박수 측정**: MAX30105 센서를 이용해 강아지의 심박수를 측정
- **걸음 수 및 이동 거리 측정**: MPU6050 6축 자이로/가속도 센서를 이용해 걸음 수, 이동 거리, 속도 계산
- **칼로리 소모량 계산**: MET 값과 강아지 체중을 기반으로 칼로리 소모량 산출
- **블루투스 통신**: HM-10 BLE 모듈을 통해 스마트폰 등 외부 기기로 데이터 전송
- **실시간 데이터 및 시간별 통계 제공**: 1초, 1분, 1시간 단위로 데이터 집계 및 전송

## 하드웨어 구성

- **Arduino 기반 보드**
- **MAX30105**: 심박수 측정 센서
- **MPU6050**: 6축 자이로/가속도 센서
- **HM-10**: BLE 블루투스 모듈
- **기타**: 점퍼선, 배터리 등

## 사용 라이브러리

- `MAX30105.h`, `heartRate.h` (심박 센서)
- `I2Cdev.h`, `MPU6050.h`, `Wire.h` (자이로/가속도 센서)
- `SoftwareSerial.h` (블루투스 통신)
- `ArduinoJson.h` (JSON 데이터 처리)

## 설치 및 사용법

1. **하드웨어 연결**
   - 각 센서 및 블루투스 모듈을 아두이노 보드에 연결합니다.
2. **라이브러리 설치**
   - 위에 명시된 라이브러리를 Arduino IDE에서 설치합니다.
3. **코드 업로드**
   - `project_heddy.ino` 파일을 아두이노 보드에 업로드합니다.
4. **블루투스 연결**
   - HM-10 모듈의 이름은 `"Heddy"`로 설정되어 있습니다. 스마트폰 등에서 `"Heddy"`로 검색하여 연결합니다.
5. **데이터 수신**
   - 시리얼 모니터 또는 블루투스 앱을 통해 실시간 데이터를 확인할 수 있습니다.

## 데이터 포맷 예시

블루투스를 통해 전송되는 데이터는 JSON 형식입니다.

```json
{
  "velocity_kmh": {"x": 0.5, "y": 0.2, "z": 0.1},
  "distance": {"x": 0.01, "y": 0.02, "z": 0.00},
  "gyroscope": {"x": 123, "y": 456, "z": 789},
  "MET": 3.0,
  "dogWeight": 10.0,
  "avgSpeedKmh": 1.2,
  "caloriesBurned": 5.6,
  "steps": 20,
  "heart": {"bpm": 110}
}
```

## 참고 사항

- 강아지 체중(`dogWeight`)과 MET 값은 코드 내에서 직접 수정할 수 있습니다.
- 데이터 전송 후 블루투스 모듈로부터 `"DATA_RECEIVED"` 메시지를 수신하면 정상적으로 데이터가 전달된 것입니다.
